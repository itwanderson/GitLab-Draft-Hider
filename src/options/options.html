GitLab Draft Hider

Hides drafts and parked merge requests from GitLab's merge request lists and keeps them in a Hidden tab, so the list only shows work that is ready.

Labels that mean "not ready"

Matches the label name exactly, ignoring case. dependencies does not match dependencies-java.

GitLab hosts

gitlab.com is always enabled. Add another GitLab to use this there, including a self-hosted one under a path such as https://example.com/gitlab.

How this works without a token

This extension has no token and stores no secret. It reads the merge request list with the GitLab session you are already signed in with, using the same read-only query the page itself uses. It can only read what that page can read, and it can change nothing.
